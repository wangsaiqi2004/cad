# 户型校准与人工修正（正式必经步骤）

## 为什么必须人工做

没有任何可靠开源方案能把上传的户型图片 / PDF 自动转成**带尺寸**的结构化平面。
软件不做「自动识别成功」的假象，不编造识别率。所有自动推测（比例注记、门宽先验）
只能作为「待人工确认的初值」并显著标注；**尺度来源必须是用户提供的已知真实距离**。

## 校准步骤（复用两点已知距离校准）

1. 选择一张底图（户型图 / 现场照片 / PDF 页图）作为校准底图。
2. 在底图上点两个位置**明确、距离已知**的点（如一段已量过的墙的两端）。
3. 输入这两点的**已知真实距离（mm）**；软件按 mm/像素换算比例，不猜测比例。
4. 逐条完成以下待确认项，未完成前任务**停在「等待尺寸确认」**，不显示百分比、不自动推进：
   - 比例未知
   - 关键尺寸缺失
   - 薄内墙待补
   - 门窗洞口待核对
   - 结构墙判断待确认
5. 人工修正：补漏薄内墙、合并 / 拆分房间、核对洞口与尺寸链、确认承重墙判断。
6. 全部确认后才生成版本化结构化平面数据（单位 mm），交给两条 CAD 发射器。

## 界面与记录

- 待确认项逐条列出，必填项完成前「确认并继续」不可用。
- 记录校准人、校准时间、两点坐标、已知距离与换算比例，供后续版本追溯。
- 需求字段里「从资料提取」的值一律是候选值 + 来源文件 + 待确认，确认前不作为事实。
